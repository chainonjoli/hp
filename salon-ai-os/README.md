# Salon AI OS

**AIスタッフが24時間働くサロン** を実現する、個人サロン向けプラットフォームの設計＆プロトタイプ。

AIを「チャットボット」ではなく、**受付・美容カウンセラー・マーケティング・顧客管理・教育** の5つの部署として機能させ、サロン情報を一元管理する **AIナレッジ** から全部署が回答・生成を行う。

## プロトタイプの見方

`prototype.html` をブラウザで開くだけで動作します（サーバー・ビルド不要）。

- 上部の切替で **お客様画面 / 管理画面** を行き来できます
- **ナレッジ連動デモ**: 管理画面 →「AIナレッジ」→ FAQを1件追加 → お客様画面のAI受付にその質問をすると、いま追加した回答が返ります（キャンペーン・基本情報の変更も同様に反映）
- お客様画面: AI受付チャット / 3ステップの肌悩みカウンセリング / 3タップ予約 / LINE導線
- 管理画面: ダッシュボード（AIからの申し送り）/ ナレッジ8カテゴリ / SNS投稿生成（IG・リール・Threads・LINE・ブログ・GBP）/ 顧客カルテ / 教育クイズ

デモデータは伊勢市のエステサロン **chainonjoli** を使用。ライト/ダークテーマ両対応、スマホファースト。

## 開発フェーズ

- **Phase 1（本プロトタイプの範囲）**: AI受付 / AI美容カウンセラー / FAQ / 予約導線 / LINE導線 / 管理画面
- **Phase 2**: カルテ / SNS連携 / 商品管理 / 分析 / 教育
- **Phase 3**: 予約枠管理 / 決済 / EC / API連携 / 多店舗

詳細は [`docs/DESIGN.md`](./docs/DESIGN.md) を参照。
